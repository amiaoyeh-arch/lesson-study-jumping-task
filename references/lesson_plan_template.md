# 新北市立國民小學 學習共同體公開課教學活動設計（公版規範）

本教案範本為新北市學習共同體標準格式，所有欄位名稱、表格結構與排列順序必須保持 100% 一致。

---

## 📋 教案標準表格欄位順序

1. **基本資料表**：
   - 授課年級、教學時間（40分鐘）、任教學科、教材版本、教學單元、教學者/備課團隊。
2. **教學設計理念與核心素養對照表**：
   - 包含學習共同體哲學理念（潤澤課堂、互惠聆聽、伸展跳躍）。
   - 總綱與領綱核心素養、學習表現、學習內容標準代碼與條文。
3. **教材組織與學生起點行為分析**：
   - 先備經驗（Low Floor 基礎知識）。
   - 本節課核心突破點（Jumping Task 伸展跳躍任務）。
   - 後續學習連結。
4. **四大維度 13 項教學設計理據表**：
   - **維度一：課程與教材設計（4項）**：1. 教材結構化分析、2. 概念定位、3. 學習起點診斷、4. Jumping Task 挑戰性設計。
   - **維度二：學生學習鷹架（3項）**：5. 自主探究任務、6. 異質協同共學機制、7. 認知衝突引導。
   - **維度三：課堂言談與傾聽（3項）**：8. 傾聽關係營造、9. 言談權力轉移、10. 六大理答對話預想。
   - **維度四：評量與反思統整（3項）**：11. 形成性評量、12. 多元表徵互學、13. 學習札記與後設認知。
5. **40 分鐘四階段課堂教學活動流程（逐字引導）**：
   - **階段一：暖身自學（Low Floor，5~7分鐘）**：個人獨立動筆、喚醒舊經驗。
   - **階段二：小組共學（Jumping Task，15分鐘）**：4人小組異質協同、突破瓶頸。
   - **階段三：全班互學（High Ceiling，12~15分鐘）**：小組發表多元解法、對話激盪。
   - **階段四：總結反思（Consolidation，5分鐘）**：個別書寫學習單札記、沉澱收穫。
6. **六大理答對話策略預想表**：
   - 學生迷思/卡點 $ightarrow$ 教師引導句型（轉引/轉問/反問/提示/釐清/深究） $ightarrow$ 預期學生頓悟。
7. **觀課記錄與議課焦點表**：
   - 學生傾聽姿態、言談參與度、認知跳躍時機記錄。
8. **學生課堂專用學習單**：
   - 暖身自學區、跳躍挑戰區（思考/算式/幾何畫圖）、課堂反思札記區。
